# Sources and licenses

The full portable distribution contains separately selected Human Input MCP and original Desktop Touch MCP components, their bundled runtimes, and the stable manager. Original Touch remains unchanged and has its own independent update lifecycle. This file is a distribution map; authoritative third-party terms remain in the original license files shipped with each component.

- Human Input MCP 0.2.0: MIT, project LICENSE. The fixture C# source under scripts/fixture is project test code loaded by Windows PowerShell; it does not add a production C#/.NET dependency to Human Input.
- Rust worker and portable supervisor: locked dependency versions, SPDX licenses and repositories are listed in licenses/cargo/manifest.json. Original crate license files, including Windows bindings and Serde, are preserved in corresponding package subdirectories. Both project executables use static MSVC CRT. Microsoft Visual C++ runtime is not redistributed as a project runtime installer.
- Node.js 24.22.1 Windows x64: official nodejs.org distribution. Each bundled runtime retains its original LICENSE, README and CHANGELOG, including Node's embedded third-party notices. Archive and executable hashes are recorded by package provenance.
- ghost-cursor 1.4.2: https://github.com/Xetera/ghost-cursor . Used for path planning; exact package integrity is pinned in package-lock.json. MIT license retained in licenses/ghost-cursor-LICENSE; bezier-js license retained separately.
- human-type rhythm planner reference, commit c6d2e94d133c2d98406f738b0ebf27a92899aec3: https://github.com/at0m-b0mb/human-type . MIT, Kailash Parshad; original license in licenses/human-type-LICENSE. Referenced for JavaScript rhythm/correction implementation. No Python source or interpreter is required by this product. New planner guarantees are tested independently and are not advertised as byte-identical random output.
- Earlier local desktop-touch-human-plugin 0.3.2: MIT, conceptual/planning baseline; project LICENSE retained. No module is loaded from that installation.
- @modelcontextprotocol/sdk 1.32.2, tar 7.5.22 (manager), and transitive Node dependencies: pinned versions and integrity in the applicable lockfiles. Original licenses remain in distributed npm package directories; package provenance records manager runtime dependencies.
- Original @harusame64/desktop-touch-mcp 2.3.2: unchanged official npm package and independently verified runtime. Original source, package metadata and licenses remain inside its separately selected component. Human Input does not import that component at runtime.
- Microsoft .NET 10.0.13 core and Windows Desktop runtime: official verified distributions bundled only for original Touch's required helpers. Original LICENSE and ThirdPartyNotices files are retained under that component's dotnet directory. Exact upstream archives, SHA512 and sources are recorded in build provenance.
- Microsoft Visual C++ v14 x64 Runtime: external system prerequisite for original Touch native modules. The launcher checks availability and links to Microsoft's installer; it does not install or relicense that runtime.

Portable sealing includes the original license files in component file lists and hashes. Final rebuilt source and portable archive provenance is recorded by the final delivery process; stale candidate hashes do not identify later reviewed source. No third-party license text is replaced by this summary.
